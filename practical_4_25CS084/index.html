JavaScript uses methods such as document.getElementById(), document.querySelector(), and document.querySelectorAll() to select elements from the Document Object Model. Once selected, developers modify attributes, inline styles, text content, or toggle CSS classes using element.classList.add(), remove(), or toggle().

We utilize the browser's localStorage API. When the user taps the theme toggle button, the new state ('light' or 'dark') is saved via localStorage.setItem('wdf_theme_25cs084', theme). When the page reloads, an immediate script checks localStorage.getItem() and sets document.documentElement.setAttribute('data-theme', theme) before render.

We bind click events on accordion buttons, modal open/close controls, hamburger toggles, and slider navigation. Additionally, global keydown events listen for the Escape key to close active modals, and ArrowLeft / ArrowRight keys to cycle through slider slides.

Every button utilizes semantic <button type="button"> elements, descriptive aria-label tags, and state flags such as aria-expanded and aria-hidden. Contrast ratios meet WCAG AA standards in both light and dark themes, and interactive items feature high-visibility keyboard focus rings.
